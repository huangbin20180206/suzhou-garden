# 苏州园林 · 附件建议审计与电脑端实施路线图

> 审计日期：2026-09-25
> 审计对象：`docs/constraints-and-upgrades.md`
> 范围：只做电脑端；移动端/平板端按用户要求暂缓。
> 原则：附件中的“现状”可能已过时，所有判断以当前代码、提交记录与专项门禁为准。

---

## 1. 总结

附件不是全部错误，但它是 2026-09-24 的静态盘点，部分建议已经在之后完成，部分建议与当前产品定位或实际收益不匹配。

### 已完成

- GTAO 半分辨率：`src/10-post.js` 已有 `AO_SCALE = 0.5`，并正确包装 `setSize`；专项 `probe/gtao-halfres.mjs`。
- Reflector 自适应更新：静止降频、相机/雨/流转/长曝时恢复满速；专项 `probe/reflect-adaptive.mjs`。
- 真实加载进度：`WARM_STAGES` + `setWarmUI()`；专项 `probe/loading-guard.mjs`。
- 投喂、上元灯会、四季自动演示、音景、导览、长曝光明信片均已落地。
- mist 判据稳定化、bank 悬空、布局指纹、门禁明细/重试、PWA 缓存治理均已完成。

### 本轮认可并纳入

1. 电脑端画质档位、4K 预算、动态超采样与更平滑 QOS 合并为一套系统。
2. 画质模式可见、可锁定，修复“系统自动降档但用户不知道/不能阻止”。
3. PMREM 按晨/午/暮/夜缓存并渐变切换。
4. 灯笼改为聚光灯；只为高画质档开启有限投影，避免五盏点光立方阴影。
5. 程序化石材/木纹等关键贴图从 512 提升到 1024，保留离线与程序化定位。
6. 固定步长仿真，低帧率下速度不膨胀。
7. 水面 Fresnel 改为更明确的 Schlick 曲线。
8. 涟漪容量 20 → 64，保留雨滴配额与点击/鱼跃槽位优先级。

### 明确不纳入本轮

- 高模商业资产：动摇“全程序化 + 离线”定位，需另行拍板。
- 8192 阴影与 CSM：6144 已足够，8192 显存高；CSM 与现有自动拟合盒整合风险大。
- TAA：植被/灯笼运动会产生拖影；先做动态超采样。
- SMAA/FXAA：当前已有 MSAA 4× + SSAA，SMAA 可能把瓦垄和竹叶细节糊掉。
- 全屏体积雾：已有全局雾、低空雾絮和灯笼体积光；再加 raymarch 收益不确定、性能风险高。
- VSM/PCSS：Three.js r184 的 PCF 路径稳定，VSM 漏光与额外 blur 风险大于收益。
- 屏幕空间折射/多角度折射：当前俯视折射已经稳定且成本低，侧面缺失是低频观感问题。
- 植被 LOD：当前三角形预算仍健康，桃树填充率贴近门禁线，暂不冒险改叶量。
- 人物骨骼动画、灯笼柔体绳：对当前写意点景人物属于风格变化，不是必要优化。
- Boids 全量替换固定鱼轨道：会破坏构图、投喂回原轨道与折射层验证；保留“固定轨道 + 投喂吸引”的设计。
- 真柔体、CDN、后端：违背当前产品定位或超出显示优化范围。

## 2. 附件逐项审计

### 1. 渲染管线与分辨率

| 附件项 | 当前真实状态 | 决策 | 原因 / 落地方式 |
|---|---|---|---|
| 1.1 GPU 两档正则 | 未完成；`?tier=mid` 能解析，但 mid 实际走 high | **认可，电脑端实施** | 建立真正的 low/mid/high 画质配置；自动档仍保守判断，UI 允许用户覆盖 |
| 1.2 超采样 1.15 | 仍是 1.15 | **部分认可** | 不上 TAA；将超采样并入 QOS，头部档允许更高，掉帧自动回落 |
| 1.3 像素预算 1440p | 仍是 high≈1440p | **认可，电脑端实施** | high 档开放 4K 预算；由统一 QOS 控制倍率，避免 DRS/QOS 双轨 |
| 1.4 QOS 四档跳变 | 仍是四档 | **认可，电脑端实施** | 增加中间档：先轻降分辨率，再降阴影/关 AO；支持用户锁定 |

### 2. 光影与后处理

| 附件项 | 当前真实状态 | 决策 | 原因 / 落地方式 |
|---|---|---|---|
| 2.1 6144 阴影 / 8192 / CSM | 当前 6144 + 自动拟合盒 + 按需更新 | **不认可本轮升级** | 已足够；8192 显存高，CSM 风险大于可见收益 |
| 2.2 点光不投影 | 5 盏 PointLight，castShadow=false | **认可，电脑端实施** | 改聚光灯并仅高画质有限投影，兼顾立体感与成本 |
| 2.3 GTAO 全分辨率 | **附件过时，已完成半分辨率** | **已完成** | `f8310fd` + `gtao-halfres` |
| 2.4 PMREM 只烘白天 | 属实 | **认可，电脑端实施** | 缓存四时段环境贴图，稳态零重烘；天气只调强度/选最近缓存 |
| 2.5 无后处理 AA | 属实，已有 MSAA4 + SSAA | **不单独实施 SMAA/TAA** | 动态超采样优先；TAA 会拖影，SMAA 可能糊细节 |
| 2.6 无体积雾 | 属实，但已有 FogExp2 + mistField + 灯笼体积光 | **本轮不新增全屏体积雾** | 氛围收益不确定，性能风险高 |
| 2.7 PCF 非软阴影 | 属实 | **不升级 VSM/PCSS** | 当前 6144 下边缘已较细，VSM 漏光风险不值得 |

### 4. 物理与仿真

| 附件项 | 当前真实状态 | 决策 | 原因 / 落地方式 |
|---|---|---|---|
| 4.1 风无空间性 | **附件低估现状**：已有局部阵风距离衰减 + 全局尾巴 | **不重写** | 保留可读的三层调度；不引入破坏档位感的全连续噪声 |
| 4.2 dt 夹 50ms | 属实，固定步长未实现 | **认可，电脑端实施** | 固定 1/60 步进 + 累加器，限制最大补步防卡顿雪崩 |

| 4.6 环境状态机 | 属实 | **保持现状** | 过渡插值是正确产品行为 |

## 3. 新实施批次

### 批次 A：电脑画质系统

- 建立 `low / mid / high` 真正配置。
- high 档开放 4K 预算与动态超采样。
- QOS 增加平滑中间档。
- 面板新增画质模式：自动 / 高 / 均衡 / 性能，并支持锁定。
- 新专项：`desktop-quality-guard.mjs`。

### 批次 B：仿真正确性与水面

- 固定步长累加器。
- 涟漪容量 64。
- Fresnel Schlick 化。
- 专项：`fixed-timestep-guard.mjs`、`ripple-bounds.mjs`、水面冻结帧 A/B。

### 批次 C：材质与夜间光照

- PMREM 四时段缓存与渐变切换。
- 灯笼聚光灯有限投影。
- 关键程序化贴图提升到 1024。
- 专项：`pmrem-env-guard.mjs`、`lamp-guard.mjs`、`festival-guard.mjs`、`warmboot-guard.mjs`、冻结帧 A/B。

### 批次 D：综合验收

- 只跑上述相关专项 + `check` + `import-audit` + `smoke`。
- 生成电脑端画质对比图。
- 不默认运行全量门禁；只有发布节点才跑全量。

---

## 4. 明确验收原则

- 日常改动不跑 36 门全量链。
- 每项先跑专项状态门，再跑相关视觉/行为门。
- 新 shader/pass/灯光只跑 warmboot、pageerror 与对应功能门。
- 任何全量门禁只在阶段发布前运行。
- 用户价值优先：4K 清晰度、正确的时段反射、可见的画质控制先于大型架构重构。
