## 已落实的优化

1. 渲染预算在 resize 时立即生效，复用 QOS/AA 路径，避免等待下次自适应改档。真实浏览器低档从 1280×720 放大至 3840×2160 后，倍率为 0.524404，canvas 为 2013×1132，实际 2,278,716 像素，低于预算 2,280,960。原倍率 1 沿用时会绘制 8,294,400 像素；本次约少处理 72.5% 的画布像素。帧率收益另按同设备、同机位和同负载量测。
2. 产品按钮复用业务入口，删除 HTML 中依赖调试对象的相机与字幕副本，机位与文案只维护导览实现。
3. 两个关键静态服务器共享零依赖路径解析器；开发缓存、MIME 与 HOST 约定保留。
4. 运行边界单测提取真实实现片段并注入依赖，在 Node 里不加载整园 WebGL；浏览器补齐生产裁剪、同页 hash、动态 resize 与依赖失败。
5. 增加 unit:coverage 和 test:edges；新回归纳入日常 unit，全量门从 102 增至 105，quick 从 21 增至 23，同步文档计数。
