## 1. 前置准备

### 1.1 需要什么

- **两台手机**：一台 iPhone（iOS Safari）、一台 Android（中低端机型优先）。
- **一台电脑**（Windows/Mac/Linux 均可）：用来跑静态服务器。
- **数据线或同一局域网**：手机要能访问电脑的 `127.0.0.1:8935`。
  - 同一 WiFi 下：手机直接访问 `http://<电脑IP>:8935`。
  - 不同网络：用数据线连电脑，手机开「USB 网络共享」或用 `adb reverse tcp:8935 tcp:8935`（Android）。

### 1.2 怎么把网页跑起来

项目 README 已写明（`README.md:43-56`）：

```bash
npm install          # 只为本地开发（three + esbuild）；页面本身不依赖 node_modules
npm run serve        # 静态服务器 → http://127.0.0.1:8935
```

> ⚠️ **不要用 `file://` 直接打开** `index.html` —— ES module 与 `.glb` 会被 CORS 拦下。
> 必须经由 http 服务（`npm run serve`、`python -m http.server` 或任意静态托管）。

**步骤**：
1. 电脑上打开终端（Windows 用 PowerShell）。
2. `cd E:\ai_test\codex_test\suzhou-garden`
3. `npm install`
4. `npm run serve`
5. 浏览器打开 `http://127.0.0.1:8935`，能看到园林页面即成功。

## 3. 常见问题速查

### 3.1 页面空白 / 白屏

**先试**：
1. 确认电脑上的 `npm run serve` 还在跑（终端窗口没关）。
2. 确认手机和电脑在同一局域网，或数据线已连。
3. 浏览器刷新。

**还不行**：截图发回。

### 3.2 按钮点不动

**先试**：
1. 确认是「方印」按钮（左下角方形）还是面板内按钮。
2. 方印：点正中，别点边缘。
3. 面板内按钮：先展开面板再点。

**还不行**：截图发回，说明是哪个按钮。

### 3.3 横竖屏切换后错乱

**先试**：
1. 旋转手机后等 2 秒。
2. 刷新页面。

**还不行**：截图发回，说明是竖屏还是横屏下错乱。

## 4. 回报方式（给未来的 MobileBot）

### 4.1 用户怎么发截图

- 直接发到这个对话里。
- 每张图注明：
  - 机型（iPhone 13 / 小米 10 等）
  - 系统版本（iOS 16 / Android 12 等）
  - 浏览器（Safari / Chrome 等）
  - 是竖屏还是横屏
  - 如果是问题，描述「点了哪里、该看到什么、实际看到什么」

### 4.2 Bot 怎么读图

按清单逐项核对：

1. **对照「该看到什么」列**：图里有没有方印、面板是否展开、按钮是否 ≥44px（目测）。
2. **对照「不对劲算不算问题」列**：如果图里显示的是「问题」状态，记录为「真机问题」。
3. **查出处列**：如果用户报的问题在清单里有对应项，读对应的 `file:line` 确认是不是产品缺陷。
4. **不在清单里**：记录为「待确认」，不编结论。

### 4.3 判断标准

- **清单内问题**：对照出处列的 `file:line`，确认是产品缺陷还是用户操作问题。
- **清单外问题**：如实记录，说「需现场确认」，不替项目下结论。

## 5. 清单里「需现场确认」的项

- 双指缩放的流畅度（清单里只写「能缩放」，没写帧率阈值）。
- 发烫程度（清单里只写「温烫可接受」，没写温度阈值）。
- 横屏下按钮是否超出右缘（清单里写「所有按钮都在屏幕内」，但不同机型宽度不同，需实测）。
